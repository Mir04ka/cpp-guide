9 лаба по С++(потоки)

Меня попросили написать следующее в main.cpp:
```cpp
double w;
w << cin;
w >> cout;
```
`w << cin` должен ввести число только с дробной частью, то есть нельзя ввести просто 5 или 5.0(так как это тоже целое по сути). 
`w >> cout` должен вывести число в формате "double=1.1234"

Для этого просто перегружаем операторы сдвига для double, пишем прямо перед функцией main:
```cpp
istream& operator<< (double& d, istream& is) {
  do {
    is >> d;
  } while ((int)d == d);
  return is;
}

ostream& operator>> (double& d, ostream& os) {
  os << "double=" << d;
  return os;
}
```
Тут важно, что порядок аргументов отличается от обычной перегрузки операторов для ваших классов потому что так надо по заданию
