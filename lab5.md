Cpp лаба 5(коллекция)
Она может попросить создать новый объект коллекции и написать код в функции main, который переносит элементы по определенному условию из первой коллекции во вторую. Код можно писать только в функции main, то есть классы менять нельзя. У меня было задание перенести покупки, цена которых была больше 5:
```cpp
//...
PurchaseCollection pc;
PurchaseCollection pc2;

Purchase* pur1 = new Purchase("Milk", 1.33, 2);
Purchase* pur2 = new Purchase("Cola", 5.15, 2);
Purchase* pur3 = new Purchase("Meat", 14.67, 2);
Purchase* pur4 = new Purchase("Bread", 1.00, 2);

pc.add(pur1);
pc.add(pur2);
pc.add(pur3);
pc.add(pur4);

int pcSize = pc.getSize();
for (int i = 0; i < pcSize; ) {
  Purchase* curPur = pc.get(i);
  if (curPur->getPrice() > 5.0) {
    Purchase* newPur = new Purchase(*curPur);
    pc2.add(newPur);
    pc.remove(i);
    pcSize--;
  }
  else {
    i++;
  }
}
//...
```
Выглядеть это должно не обязательно так, но главная идея в том, что мы не можем просто копировать значение из коллекции в коллекцию: тогда у нас ссылка на один и тот же объект будет в двух коллекциях. Это плохо, так как когда первая коллекция будет уничтожаться, она уничтожит все элементы, а когда вторая коллекция будет уничтожаться, она попробует уничтожить объект, который уже уничтожила первая коллекция и программа крашнется.
Поэтому мы проходимся по первой коллекции, каждый элемент сравниваем и если он удовлетворяет условию мы создаем его копию, копию добавляем в коллекию 2, а в из первой коллекции удаляем этот элемент.
Есть вероятность, что такое задание она и не даст, но все же
