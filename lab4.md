В 4 лабе по С++(наследование) одно из возможных ее заданий следующее:
```cpp
int len;
int k = pur2.countStr(len);
k = pur2.countStr(len);
```

Функция countStr должна вернуть количество строковых полей(string), а len должен принять значение суммарной длины этих строк. Это задача на переопределение функций в классе-наследнике. Решается так:
1. В классе-родители пишем функцию:
```cpp
int Purchase::countStr(int& len) {
  len += productName.length();
  return 1; // так как в этом классе 1 string
}
```
2. В классе наследнике пишем такую же функцию, но с другой логикой:
```cpp
int CreditPurchase::countStr(int& len) {
  len = bank.length(); // !важно, чтобы при повторном вызове функции с теми же параметрами в main len не продолжило увеличиваться, здесь мы задаем ее значение, а не прибавляем
  return 1 + Purchase::countStr(len); // 1 - количество string в классе-наследнике + количество строк в родителе
}
```
3. Теперь даже при двойном вызове мы получим одинаковые результаты:
```cpp
int len;
int k = pur2.countStr(len);
k = pur2.countStr(len);
k = pur2.countStr(len);
```
