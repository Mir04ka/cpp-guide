На cpp при сдаче 2 лабы она может попросить сделать динамический/обычный массив вашего класса и заполнить его с клавиатуры(используя метод класса). А потом она попросит написать новый метод класса для работы с массивом внутри класса. 

Например:
```cpp
// main.cpp

Animanl arr[4];

for (int i = 0; i < 4; i++) {
  arr[i].input();
}

int age_sum = arr[0].ageSum(3); // Подсчитать сумму возрастов 3 животных из массива начиная с того, для которого метод вызван
```

Это делается примерно так:
```cpp
// Animal.cpp

int Animal::ageSum(int n) {
  int sum = 0;
  Animal* arr = this;
  for (int i = 0; i < n; i++) {
    sum += arr[i].age;
  }
  return sum;
}
```
